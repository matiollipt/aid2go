How to read this gallery

Current artifacts describes the audited 4,997-protein / 1,000-term pipeline dataset. Saved holdout example describes the separate 1,000-protein / 100-term seed-42 experiment, with 100 held-out test proteins. These populations are kept separate.

Hover marks for exact values. Click a GO point to locate the same term across six embedding panels. Change network, curve, and explanation controls to explore each proposal. No invented scores or simulated learning curves are included.

Explore a protein’s ESM neighbors

Choose any protein from the dataset. Start with its direct neighbors, then expand to two or three hops. The graph preserves edge direction and similarity values; pan, zoom, or click a node to make it the new root.

0.00

Hops follow either incoming or outgoing links; arrows retain the original direction. Root: orange; one-hop neighbors: blue; two/three-hop neighbors: purple/gray. Node size reflects incoming degree; edge width reflects reconstructed cosine similarity. Current KNN topology was selected using L2, and its weights are not consumed by the baseline model. Layout rings encode hop count, not embedding distance.

This is a sequence-similarity network, not an experimentally established protein–protein interaction network. Node and edge limits protect readability; the graph reports omitted counts and retains connections from every displayed node to the root.

08

Training and evaluation trajectory

Use aligned small multiples to keep loss separate from performance. The current history records training loss and validation metrics, but does not provide enough evidence to diagnose overfitting from loss gaps.

Training loss by epoch

Current pipeline: BCE, five epochs, one full-graph optimizer update per epoch.

Validation performance by epoch

Current pipeline’s sampled-link validation AUPR and Fmax; higher is better. The test set is not used to select an epoch.

Best-checkpoint train / validation / test diagnostics

Recomputed from the current best checkpoint on each split’s own message-passing graph. Negative pairs are recreated with the corrected full-RNG seed policy; recorded epoch metrics predate that fix. These are checkpoint diagnostics, not missing per-epoch validation losses and not a strict overfitting gap because contexts differ.

Recommended capture: log train and validation loss plus PR-AUC on a fixed scoring protocol every epoch; plot the gap and selected checkpoint. Add gradient norm, optimizer steps, learning rate, and time/GPU memory. Keep test evaluation separate and run it after checkpoint selection.
09

ROC / AUC, alongside precision–recall

ROC separates ranking from a decision threshold. PR makes the consequences of sparse positive annotations visible. Always display prevalence and the scoring population.

Receiver operating characteristic

Dashed diagonal is the random-ranking reference. AUC is calculated on the full score arrays; displayed curves are downsampled only for rendering.

Precision–recall curve

Dashed line is positive prevalence for the selected population. PR-AUC uses trapezoidal area; it is not average precision.

Current test links contain sampled negatives and approximately 50% positive prevalence. Dense function prediction is much sparser. AUC/AUPR from those two protocols should not be compared as if they were the same benchmark. Missing annotations are evaluation negatives, not confirmed biological negatives.
10

Plots aligned with CAFA evaluation

Use protein-centric precision/recall, semantic error, threshold sensitivity, and coverage for each aspect. These previews apply CAFA-style definitions to an internal holdout; official benchmark eligibility still requires a compatible target cohort, ontology, evidence policy, and IA reference.

0.50

Protein-centric precision–recall

Precision averages over proteins with predictions; recall averages over eligible proteins with aspect annotations. Dot marks the inspected threshold.

Remaining uncertainty × misinformation

RU = missed true information; MI = predicted information absent from targets. Both are IA-weighted bits per eligible protein. Minimum distance to (0,0) is Smin; lower is better. Axes use independent ranges; distances are computed in unscaled bits. The dark dot marks Smin.

F1 and coverage versus threshold

Coverage is the fraction of eligible aspect targets with ≥1 prediction. High score without useful coverage can be misleading.

Semantic distance versus threshold

S(τ) = √(RU² + MI²). Report Smin and its threshold, not “Smax.” The code’s legacy smax key currently stores a minimum.

Real saved holdout data: 100 proteins × 100 selected GO terms. Scores and targets are propagated through the complete is_a / part_of ontology and projected back onto the selected vocabulary; ontology roots are excluded. IA comes from the sample’s training cohort. This remains an incomplete-vocabulary internal evaluation, not a certified CAFA result. Changing scope/propagation means these recomputed values can differ from the stored experiment report.
Protocol checklist before an official CAFA readout
  • Use the challenge’s release, target list, evidence criteria and target eligibility; separate no-knowledge and limited-knowledge targets as required.
  • Propagate truth and scores through valid is_a and part_of paths. Decide roots/orphans and obsolete-term mappings according to the evaluator protocol.
  • Use the specified IA reference; estimate internal IA from training annotations only. Record term coverage and absent/out-of-vocabulary labels.
  • Report BP/MF/CC separately with denominators, coverage, Fmax, Smin, PR-AUC and protein-bootstrap uncertainty. Fix operational thresholds using validation, not test.
  • Run the reference CAFA evaluator and cross-check the exported tables before describing a result as a challenge benchmark.
11

Explain a predicted link

Show a prediction’s model sensitivity beside its local evidence. Embedding feature importance, attention, and edge-removal effects answer different questions and should have separate legends and units.

Saved holdout example

Feature sensitivity · |gradient × input|

Top saved embedding dimensions for the protein and GO node. Dimensions are representation coordinates, not named amino acids or biological pathways. No residue attribution is available for this node-based encoder.

Prediction change after edge removal

Δscore = score after removal − original score. Negative values mean the removed edge supported this prediction. Annotation edges and their reverse counterparts are removed together.

Attention on the inspected neighbors

Degree-attention model only: head-averaged coefficients from the last layer, normalized within relation/destination. Baseline has no attention values; unavailable coefficients are not plotted as zero.

Attention versus removal sensitivity

Same inspected neighbors; x = saved attention, y = Δscore on removal. Use this as a local faithfulness diagnostic, not as proof that attention is causal.

TP / FP / FN refer to the observed annotation matrix at the validation-selected threshold. A reported FP may be an unannotated biological function. Edge-removal diagnostics cover a bounded set of neighbors, not exhaustive explanations. Attention, gradients and perturbations are model evidence, not causal biological evidence.

Suggested training / evaluation capture changes
  1. Extend epoch history with fixed-protocol train_eval_loss, val_loss, train_aupr, learning rate, gradient norm and optimizer steps. Keep the existing columns backward-compatible.
  2. Persist raw validation/test score arrays with protein IDs, GO IDs, split manifest, checkpoint hash, ontology version, IA reference, and prediction context. Use those rows as the single source for ROC, PR, calibration and CAFA plots.
  3. Retain ESM cosine/L2 edge values in a companion artifact; current models do not consume weights, so enabling weighted message passing is a separate modeling change.
  4. Save raw and true-path-adjusted scores, per-aspect threshold sweeps and coverage. Add smin as the descriptive name while supporting the existing smax alias.
  5. Reuse the existing explanation JSON exporters; add signed attribution and controlled deletion curves if stronger faithfulness evidence is needed. Save attention only for models that expose it.

Sources

Design references and provenance

The page adapts the following ideas into a scientific artifact gallery. Sources are linked directly; chart values come from local artifacts, not reference-site examples.

Storytelling with Data · decluttering

Quiet gridlines, sparse labels and clear hierarchy keep attention on the observations.

Data to Viz · network diagrams

Use edge semantics deliberately and bounded neighborhoods to avoid unreadable full-network hairballs.

Distill · How to Use t-SNE Effectively

Hold projections fixed while changing encodings, and avoid treating island area or separation as quantitative biological evidence.

UMAP · reproducibility

Fix the random state and report parameters; single-threaded seeded fitting supports repeatable comparisons.

Gene Ontology · ontology relations

GO is a DAG with multiple parents. Keep is_a and part_of direction explicit; other relation types do not automatically share the same propagation meaning.

CAFA evaluator · benchmark definitions and plots

Use aspect-specific threshold sweeps, documented normalization and IA-weighted minimum semantic distance.
